# 本地测试结果（submit.cpp）

由 `python3 run.py bin/submit cases/*.in -o ...` 调用官方评测程序得到，逐场景数据见 [submit_results.csv](submit_results.csv)。

| 项目 | 数值 |
| :--- | ---: |
| 场景数（125 组随机/练习场景 + 6 组最大规模 + 2 组官方小样例） | 133 |
| 对账错误或非法指令的场景 | 0 |
| 利润 / 上界 U 的中位数（125 组随机场景） | 0.365 |
| 最大 CPU 时间（本机 Apple Silicon，含 6 组最大规模） | 0.448 s |
| 最大规模 6 组 CPU 时间 | 0.165 - 0.369 s |

说明：
- 场景由 `gen.py` 按题面数据范围随机生成（`cases/`），**不是 OJ 的真实数据**，利润不能直接换算成 OJ 得分。
- 上界 U 为评测程序给出的理论上界，利润 / U 只是相对指标。
- CPU 时间随机器而异，OJ 上以评测结果为准。
